# Greek Food — React/Vite build

This is the React version extracted from the supplied HTML/React source.

## Run

```bash
npm install
npm run dev
```

Then open the localhost URL Vite prints, usually:

http://localhost:5173/

## Files

- `src/App.jsx` — all page components
- `src/index.css` — Tailwind + custom styling
- `src/main.jsx` — React entry point
- `index.html` — HTML5 document shell
- `vite.config.js` — Vite + React + Tailwind setup

Images are intentionally placeholders for now.
